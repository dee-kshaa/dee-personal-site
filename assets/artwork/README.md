# Original artwork files

Add your own artwork images in this folder, then add one data entry per image to `../../artworks.js` (relative to this folder, the project root file is `artworks.js`).

Supported image formats: JPG/JPEG, PNG, and WebP. Portrait, landscape, and square aspect ratios are supported. Use descriptive filenames such as `mandala-study.jpg`; in `artworks.js`, set `src` to `assets/artwork/mandala-study.jpg`.

For each piece, provide its real title, category/medium, and useful alt text. Description and image attribution are optional. No artwork images were included with the source portfolio, so this directory intentionally contains no made-up or generated artwork.
